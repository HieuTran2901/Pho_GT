## ⚡ CHUẨN MỰC KỸ THUẬT & HIỆU NĂNG (TECHNICAL INVARIANTS)

- **Quy tắc Giới hạn Kích thước Tệp**: 100% tệp mã nguồn React (`.jsx`, `.js`) đều duy trì nghiêm ngặt **dưới 500 dòng**, đảm bảo tính module hóa và dễ bảo trì.
- **Bảo Vệ Thông Tin Khách Hàng (PII Privacy)**: Số điện thoại và dữ liệu cá nhân trên giao diện công khai đều được che tự động (`098****888`).
- **Tối Ưu Hóa Re-render**: Sử dụng cấu trúc dữ liệu Set $O(1)$ (`favoriteIdsSet`, `addedItemIdsSet`) cùng `useMemo` / `useCallback` để triệt tiêu việc quét mảng dư thừa trong render loop.
- **Bảo Toàn Phiên Khách Hàng**: Lưu trữ song song đơn hàng tại `sessionStorage` (giữ vé khi reload F5) và `localStorage` (lịch sử đơn hàng cá nhân).

## 🚀 HƯỚNG DẪN CÀI ĐẶT & KHỞI CHẠY (QUICK START)

### Yêu Cầu Hệ Thống
- **Node.js**: Phiên bản 18.x hoặc 20.x trở lên
- **Trình quản lý gói**: `npm` hoặc `pnpm` / `yarn`
- **Backend Service**: Spring Boot 3.4.3 (khởi chạy tại `http://localhost:8080`)

### Các Lệnh Thao Tác

```bash
# 1. Cài đặt các thư viện phụ thuộc
npm install

# 2. Khởi động môi trường phát triển (Hot Module Replacement tức thì)
npm run dev

# 3. Biên dịch đóng gói Production tối ưu
npm run build

# 4. Xem trước bản Production sau khi đóng gói
npm run preview
```

Giao diện phát triển mặc định sẵn sàng tại: [`http://localhost:5173`](http://localhost:5173)
